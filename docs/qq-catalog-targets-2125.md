# 2125：双源分类搜索与收藏连接

维护与新增功能：tiancaiProgramer。保留 sixbugs / 2697a 原版权及 MIT 许可。

## 搜索

搜索页保留四类：单曲、歌单、专辑、歌手。两平台显示时名称为“双源…”；分类内可选择全部、网易云、QQ音乐。来源标签沿用现有主题，遵守“未登录隐藏”。分页、失败重试和迟到响应隔离沿用单曲搜索机制。QQ 搜索结果使用各自的真实歌单编号、专辑MID和歌手MID；点击后读取该目录歌曲，进入混合播放器时保留QQ来源。网易云结果沿用原详情页。

QQ分类搜索的请求信封需要使用 music.search.SearchCgiService 名称作为键，不能套用普通RPC的req_0/comm。匿名真实请求已核对歌单、专辑、歌手三类均有结果，三类均能读取真实歌曲列表；不是用歌曲关键词搜索冒充专辑/歌手目录。

## 音乐缓存

本地音乐原“网易云缓存歌曲”入口改为“音乐缓存”，内有网易云缓存和QQ音乐缓存/本地文件。网易云仍读取官方客户端的Music1目录及原uc/idx文件。

QQ入口扫描可访问的常见qqmusic及Android/data/com.tencent.qqmusic目录，按实际文件头识别普通MP3、FLAC、WAV、Ogg、MP4音频，不改名、不修改原文件，也不将未知或加密文件伪装为可播放文件。扫描范围、文件数和递归深度有限；不代表支持QQ全部缓存格式。当前手机的常见QQ和网易云缓存目录未读到文件，未声称已完成QQ缓存真机播放。

缓存不是放在同一个地方的BuYu播放缓存：现有在线播放使用网络流，不自动保存完整音频。BuYu下载的两平台歌曲从下载管理查看；系统本地曲库也可读取普通音频。官方客户端加密文件不能只改名字播放，系统保护目录也可能无法访问。

## 聚合收藏连接

入口：聚合收藏右上角连接图标，或“设置 → 音乐账号与收藏 → 聚合收藏连接”。网易云和QQ分别选择本人创建的普通歌单，按账号保存；喜欢等受保护目录不作为可写目标。

未指定时继续自动使用/创建BuYu收藏。更换时必须选择“合并并连接”“仅连接”或取消。合并会先完整读取原连接歌单，按来源合并聚合收藏和原云端歌曲，并添加到新歌单；不清空新旧歌单。读取失败时取消本次合并，保留原连接。仅连接保留本地已有收藏，不主动推送到新目标，后续新增收藏使用新连接。

切换等待进行中的旧读写结束，取消旧目标的待同步操作；不会将旧目标的删除操作发送到新歌单。各收藏记录保留所属目标和账号；非合并保留的旧本地收藏不会因为新歌单中不存在而被自动删除。目标失效时提示重新选择，不自动退回其他歌单。配置与收藏记录一起保存，来源互不串写。
