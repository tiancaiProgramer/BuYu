# BuJuan 2.0.6（2062）

发布日期：2026-10-16。基于 [2697a/bujuan](https://github.com/2697a/bujuan)，原作者 **[2697a](https://github.com/2697a) / sixbugs**。保留原项目 MIT 许可证、版权声明和第三方组件致谢；本仓库为社区修复维护版。

## 横竖屏与页面

- 首页横屏显示三列歌单并纵向滚动，每日、FM、播客、云盘保留原按钮并排列在右侧；头像侧栏沿用原版交互。
- 横屏根据重力感应自动旋转，“适配横屏”设置控制是否启用，支持左右两个方向；移除会阻止后续自动旋转的临时旋转按钮。
- 处理头像侧栏展开距离、菜单与阴影区域、摄像头两侧安全区、头像与标题对齐。
- 每日推荐增加封面；每日、云盘、本地音乐、查看/管理和设置页适配横屏，设置项横向两列并分开呈现。
- 修复冷启动横屏进入每日推荐无法返回、搜索跳转残影。
- 自定义启动图和背景可用竖图自动适应横屏，也可单独设置横屏图片；编辑页适配横屏。

## 播放与歌手

- 横屏播放页左侧放置封面、歌曲信息和播放操作，中间显示歌词，右侧保留原功能按钮。
- 修复右侧摄像头遮挡按钮、内容位置偏下、状态栏文字对比度不足、封面空白和横屏专辑渐变背景缺失。
- 修复竖屏上一首和播放模式按钮点击无响应。
- 歌手入口恢复显示，补全真实头像加载，横屏显示两列歌手歌曲推荐并沿用主题；歌手详情及播放队列适配横屏。
- 播放音质支持标准、较高、极高、无损、Hi-Res 优先级；切换音质保留当前歌曲和进度。实际规格通过加载音频头核对。

## 下载

- 播放页歌手区域新增“下载当前歌曲”，歌曲三点菜单新增“下载歌曲”。
- 默认下载音质独立于播放音质，每次下载也可单独选择；默认选中音质可直接点击提交。
- 下载弹窗展示官方资源规格和账号可下载范围，修复特定播放器主题下选项文字空白。
- 使用网易云下载接口，按当前账号权益获取；资源不可用时提示失败或按优先级回退，不使用试听片段冒充完整文件。
- 设置内可选择保存文件夹，默认 `Music/BuJuan`；使用系统授权保存到自选目录。
- 下载管理提供进度、取消、失败重试和已下载歌曲离线播放；进程中断任务恢复为可重试状态。
- 通知栏显示进度及完成、失败结果，应用内也提示结果。只有文件完整性检查和实际保存成功后才报告完成。
- 按真实音频格式保存并展示规格；请求档位和官方实际返回格式可能不同。当前不承诺系统结束应用后的持续下载或自动断点续传。

## 设置与更新

- 播放、下载音质分别配置，下载目录可修改。
- 自定义横竖屏启动图和背景保留独立选择及自动适配方式。
- 整理当前无效设置入口，应用内更新关联 `tiancaiProgramer/bujuan-fixed` 的 Releases，支持内部版本比较，避免降级提示。
- 保留 2.0.5 的播放重试与停滞恢复、信息同步、标准媒体控制、本地曲库、赞助二维码移除及体积优化。

## 验证与范围

- 完整自动检查 **105 项通过**，包括默认选中下载音质的真实控件点击检查。
- 已在小米 15 / HyperOS 3.0.307.0 覆盖安装，使用者确认“极高”、其他音质及完成通知可用。
- 自选 `Download/music` 目录实际保存成功，独立检查文件头：标准 MP3 128 kbps / 44.1 kHz；极高 MP3 320 kbps / 44.1 kHz；无损 FLAC 16 bit / 44.1 kHz / 双声道。播放侧还验证过 FLAC 24 bit / 96 kHz。
- 官方对一次“较高”请求实际返回 FLAC，应用保留真实文件并显示其规格，不将请求标签当作音频标准证明。
- 歌手头像、推荐歌曲已观察到。部分自动检查使用模拟播放器及网络；不同账号、曲目和设备仍可能存在差异。
- 超级岛所有按钮交互、本地标签写入、缓存解密及各类 TV / 车机尚未全面真机验证。
- 本次仅发布手机 APK。TV 仍为独立试用分支范围；Android 4.4、iOS、Android Auto / CarPlay、云端歌词自动匹配不在本次交付内。
