# BuYu 2.0.8（2121）未登录平台隐藏修复

日期：2026-10-29。维护与新增功能：**tiancaiProgramer**。正式发布标签：`v2.0.8.2121`，应用版本 2.0.8，内部版本号 2121。

## 修复与遗漏排查

- “每日”“播客”“每日发现”共享的平台选项接入“未登录隐藏”。即使某平台支持匿名浏览，开启隐藏时仍只显示已登录平台。
- 登录状态或隐藏开关变化后立即更新选项；当前选中平台被隐藏时自动切到可用平台，旧的来源选择记录不会重新选中隐藏项。所有平台均未登录时显示登录引导，不加载隐藏平台内容。
- 搜索页修复同类遗漏：隐藏的平台不显示来源、结果和错误提示，也不会继续发起搜索或分页请求；已发出请求的迟到结果不重新进入界面。关闭隐藏后恢复两平台搜索。网易云未登录且开启隐藏时，网易歌单、专辑、歌手标签及网易热词也隐藏；当前网易专属标签失效时回到单曲搜索。
- 歌单管理页修复来源筛选、已缓存云端歌单及新建歌单菜单的同类遗漏；本地分类和聚合收藏始终可用。
- 同一来源切换音乐账号后重建对应浏览内容，避免沿用旧账号页面。退出账号后不会因遗留账号资料反复触发加载。
- 设置说明同步更新；补齐另一处聚合收藏保存提示，说明会自动同步。
- FM 已按已登录账号列出平台，无需改动。登录页和账号管理页保留两平台入口，便于登录隐藏的平台；本地收藏中的歌曲不因平台退出而删除。

## 验证

- 新增 12 项横竖屏回归，覆盖上述三页、公开推荐来源、开关动态切换、两个方向的单账号、全部退出、保存了失效来源后的重开、搜索迟到结果和歌单管理菜单。
- 完整自动回归 **309 项通过，4 项默认联网检查跳过**。修改范围静态检查无错误或警告；仍有样式级提示。
- MIX Fold 3 已安装最终候选包，设备 APK 哈希与本地 ARM64 包一致。退出网易云、保留 QQ 并开启隐藏后，实测每日、播客、每日发现只显示 QQ，搜索不显示网易专属标签与来源，新建歌单菜单只保留本地和 QQ；主页与歌单管理隐藏网易云歌单，原三首聚合收藏保留。
- 使用者恢复网易云后，实际退出 QQ 并保留网易云，第二轮分别核对每日、播客、每日发现、搜索、歌单管理及新建菜单：QQ 选项隐藏，网易云内容可访问，网易专属搜索标签仍保留；播客返回空数据，选项显示正确。两个方向分别实测，未以其中一个方向代替另一个。
- 使用者恢复 QQ 后，复核双账号、原三首聚合收藏和两平台歌单保留，结束进程重开后仍正常；隐藏开关恢复测试前关闭状态，网络和旋转设置保持原值。当前进程日志无崩溃标记。全部退出场景由自动回归覆盖，本轮未再次实机退出两个账号。
