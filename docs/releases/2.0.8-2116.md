# BuYu 2.0.8（2116）

维护与新增功能：**tiancaiProgramer**。

在原有界面与横竖屏适配基础上加入 QQ 音乐，与网易云音乐共用播放器、搜索和聚合收藏。保留原作者 sixbugs / 2697a 版权及 MIT 许可，来源集中见 [CREDITS.md](../../CREDITS.md)。

## 双账号与双音源

- 网易云、QQ 音乐分别登录和退出，默认二维码，其他方式进入官方网页登录；各自使用本人的账号和会员权限。
- 双源单曲搜索同时查询两个平台，可筛选来源；混合队列按歌曲来源请求音频与歌词。同名的不同平台版本分别保留。
- 首页与查看/管理支持合并显示、QQ 音乐、网易云三种歌单来源；云端歌单可折叠，聚合收藏和本地分类仍显示。
- 聚合收藏读取两个平台各自的 BuYu收藏，收藏操作按来源同步；支持本机新建、改名、删除分类。不会把一平台歌曲编号转换为另一平台歌曲。
- QQ 普通歌单支持新建、改名、删除及增删歌曲，写入后读回校验，内建喜欢列表受保护。
- 仅 QQ 登录也能正常使用侧栏。两个平台均未登录时，点击头像进入登录页。
- 主页显示 QQ 音乐官方头像和昵称；双登录可在「设置 → 音乐账号与收藏 → 主页头像来源」切换并保存，退出所选平台后自动使用另一个已登录账号。

## 发现、播放与下载

- 每日、FM、播客使用现有入口选择平台；QQ FM 支持末曲自然结束后自动补歌，QQ 播客支持目录、搜索、分期列表、分页及播放。
- 云盘保持网易云来源；未登录显示登录入口。设置内“未登录隐藏”按两平台账号处理每日、FM、播客和歌单，云盘始终保留。
- QQ 评论支持热评、最新及分页查看。
- 两个平台的歌曲可按官方当前账号返回的资源播放或下载；播放音质、下载音质独立设置，保存文件夹可修改。
- 下载管理记录进度、结果、来源、请求档位、返回档位、实际文件头规格、文件大小及位置，支持失败重试。

## 布局与稳定性

- 统一来源筛选、搜索、评论和新增操作面板的主题样式。
- 横屏登录采用平台、二维码、说明按钮三列，二维码完整显示。
- 修复账号退出、仅 QQ 登录后的侧栏访问，以及切换设置时旧页面文字透出。
- 横屏四个快捷入口在歌单顶部至播放栏上方等距排列，折叠与播放控制对齐；竖屏迷你播放栏缩减多余留白并居中。
- 没有选中歌曲时隐藏空播放器，保留已有横竖屏首页和播放页操作。

## 安装

- ARM64：`BuYu-2.0.8-2116-arm64.apk`；旧 32 位 ARM 系统：`BuYu-2.0.8-2116-arm32.apk`。
- 最低 Android 5.0，Android 4.4 不支持；本次仅发布手机/平板安装包，不发布 TV 包。
- 正式包名仍为 `com.sixbugs.bujuan`，原签名可覆盖旧正式版并保留其数据。
- 共存测试版包名为 `com.sixbugs.bujuan.preview`，两者数据独立，不会自动迁移测试版账号、分类和下载记录。请在正式版单独登录，云端 BuYu收藏 可重新读取，本地分类需自行保留。
- ARM64 包约 13.8 MB，ARM32 包约 13.6 MB。
- 校验文件为 `SHA256SUMS.txt`。更新检查关联 [本仓库 Releases](https://github.com/tiancaiProgramer/BuYu/releases)。

## 验证及功能边界

完整自动回归 241 项通过，3 项联网测试默认跳过。已在已登录 QQ 的真实 Android 16 手机验证官方头像、侧栏、100 期播客分页、拖动至 30 秒、旋转后状态保留、FM 自然补歌和后台媒体控制。双账号头像切换经横竖屏自动测试；当前最后一轮真机为 QQ 单账号。

QQ《稻香》极高下载文件曾核验为 MP3 320 kbps / 44.1 kHz / 双声道；其他测试曲目的 FLAC 规格记录见 [真机验证记录](../qq-music-device-verification.md)。这些结果仅代表测试曲目，不保证所有歌曲、会员或档位都提供相同资源，按返回文件头显示实际规格，不绕过平台权限。

歌单、专辑、歌手搜索仍主要为网易云，双源合并针对单曲。QQ 评论暂不支持发表、点赞、回复，QQ 播客未接入订阅同步，QQ 云盘未接入。聚合收藏尚不自动对账删除其他设备已删的歌曲；离线播放需要下载文件。Android 5.x 的 QQ 会话只保留在当前进程，重启需重新登录。尚不保证应用被系统结束后继续下载或自动断点续传。接口可用性由各平台决定。
