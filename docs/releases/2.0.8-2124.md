# BuYu 2.0.8（2124）

维护与新增功能：**tiancaiProgramer**。日期：2026-11-01。

本次针对高音质不可用时播放失败、两平台共用音质偏好及下载档位不准确的问题，统一播放降级策略，并将下载改为严格使用所选音质。

## 更新内容

- 修复 QQ 单档取源报错、超时、返回不可用地址以及播放器加载、解码或播放中断后没有继续尝试较低音质的问题；开启降级时保留同一首歌和已有播放进度，下一首重新从首选档位尝试。
- 设置新增“播放失败时自动降低音质”，默认开启，网易云与 QQ 共用此开关。关闭后只请求所选档位，同档重试仍失败则停止并提示；不接受低档替代资源。加载中关闭开关会中断旧请求链。
- 两平台分别保存播放音质与下载音质，修改另一平台的设置不会打断正在播放的歌曲。兼容读取旧设置。
- 根据当前 BuYu 接入与真实会员账号测试，QQ 的播放、下载选项保留标准、极高、无损，移除不可用的 Hi-Res 及重复“较高”；网易云保留标准、较高、极高、无损、Hi-Res。旧 QQ Hi-Res 偏好迁移至无损。
- 下载严格按所选档位，不受播放降级开关影响。取源、地址或文件校验失败直接提示，不向下获取或保存低档替代文件；可手工重试或选择其他档位。
- 单曲下载菜单按平台支持、实际资源及接口提供的账号下载权限筛选，没有 Hi-Res 资源时隐藏该选项；查询中等待，失败可点击重试，全部不可用时显示说明。移除旧的自动回退文案。
- 网易云部分真实 Hi-Res 文件在取源接口标为 lossless：按歌曲官方 hr 文件大小核对后接受，避免误判；低档替代文件仍拒绝。保留完整文件、官方 MD5（提供时）和音频文件头检查。

## 验证与范围

完整自动回归 **361 项通过，4 项默认联网检查跳过**；修改范围静态检查没有错误或警告，仍有样式级提示。覆盖两平台取源失败、原生加载与异步错误、开关默认值及持久化、关闭时取消旧链路、不降级下载、资源匹配、单曲档位隐藏和查询失败重试。

MIX Fold 3 使用真实账号完成两平台最高保留档位播放、完整下载及离线起播：网易云样本为 FLAC 24bit/48kHz，QQ 样本为 FLAC 24bit/44.1kHz。缺少 Hi-Res 的网易云歌曲在关闭播放降级后仅请求原档并停止；直接调用下载引擎也会失败，不保存低档文件。资源查询确认有 Hi-Res 的歌曲保留该选项、无 Hi-Res 的歌曲仅到无损，QQ 最高为无损。菜单加载、过滤和重试交互由组件测试验证，不将电脑模拟点击记作实体点击验证。

测试使用独立内存音质偏好和临时文件，不修改真实音质设置、用户队列或下载历史；临时下载文件在完成后清理。此前随机 8 首歌曲、80 项逐档播放/下载记录见[音质能力核验](../audio-quality-capabilities-2123.md)，严格档位策略与完整边界见[2124 策略](../audio-quality-policy-2124.md)。这是当前 BuYu 接入和被测账号、曲目的结果，不代表所有第三方客户端或整个平台曲库的能力上限；实际资源仍取决于账号、歌曲和官方服务状态。

## 安装与更新

[GitHub 发布页](https://github.com/tiancaiProgramer/BuYu/releases/tag/v2.0.8.2124) 提供 ARM64 / ARM32 原签名正式 APK 和 `SHA256SUMS-2124.txt`。MIX Fold 3 和大多数安卓手机、平板选择 ARM64；32 位 ARM 系统选择 ARM32。原包名 `com.sixbugs.bujuan`，可覆盖更新保留正式版数据。最低 Android 5.0，本次不发布 TV 包。

版本名仍为 2.0.8，构建号从公开版 2121 升至 2124；旧正式版可通过“设置 → 检测更新”发现本次更新，状态继续在原版本号位置显示。此前已安装本次最终 2124 包的 MIX Fold 3 无需重复安装。
