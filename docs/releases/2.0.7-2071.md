# BuYu 2.0.7（2071）

日期：2026-10-18。维护与新增功能：**tiancaiProgramer**。

## 更新内容

- 修复平板横屏左侧四个菜单按钮固定间距、集中在上半部的问题。按钮与点击区域按头像下方的可用高度均分，短窗口可以滚动，手机竖屏与右侧按钮沿用原布局。
- 登录入口保留“官方网页登录”和“二维码登录”，两个按钮统一样式，修复深色主题下二维码按钮、刷新和关闭文字不可见的问题。
- 在应用内打开网易云官方 HTTPS 网页，由网页处理手机号认证和安全验证；移除受风险限制的密码及短信验证码直连表单。会话先独立校验，再保存登录状态；取消或认证失败保留原会话。
- 应用名称统一为 BuYu，更新检查和下载入口同步至更名后的 `tiancaiProgramer/BuYu` 仓库。

## 安装与验证

- 对外版本 **2.0.7**，内部版本 **2071**，包名 `com.sixbugs.bujuan`，最低 Android 5.0。
- ARM64 与 ARM32 安装包均使用原正式证书签名，支持保留数据覆盖升级。
- 完整 Flutter 回归 **133 项通过**，默认跳过 2 项历史联网检查；包括多尺寸菜单均分、短窗口、旋转、安全区、登录会话和仓库更名后的发布链接检查。
- 2070 候选已在 3040×1904 横屏平板验证菜单显示、设置入口和个人中心图标下方点击区域，升级后登录状态与歌单保留。2071 在此基础上同步更新地址，菜单实现一致。
- 网页手机号输入框及“获取验证码”显示已实机检查；实际账号输入、验证码和安全验证由用户在官方网页操作，认证验证范围见 [网页登录说明](../login-methods-2066.md)。
