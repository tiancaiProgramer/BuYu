# BuYu 2.0.9（2127）

维护与新增功能：**tiancaiProgramer**。

修复 QQ 音乐“界面仍显示已登录，但歌曲或歌单失败，需要重新登录”的会话处理缺口。

## 本次修复

- 明确鉴权失效时尝试同账号官方续期，并发请求共用一次恢复，失败后限流。
- 保留扫码返回的续期资料；官方网页登录若提供同类字段，也分别保存。资料仅保存在设备绑定的加密会话中，不进入普通请求 Cookie、公开收藏库或日志。
- 新凭据必须通过同账号资料校验并成功保存，才会替换原会话；续期失败可尝试同账号已有的更新后网页会话。
- 普通网络错误、接口业务错误和歌曲权限不足不当作账号退出；无法恢复时提供重新认证入口，并保留账号记录和收藏。
- Android 会话改用原子写入，临时读取失败不再删除文件或创建替代设备密钥；回到前台可重试读取。退出与登录保存串行，防止迟到结果恢复已退出账号。

## 验证与限制

完整自动回归 **383 项通过，5 项联网检查默认跳过**；六项会话专项检查覆盖前台重试、并发续期、网络失败、恢复失败保留记录和退出竞态。原签名正式包已覆盖安装到连接的手机，内部版本号为2127。

**自然过期尚未在本次实机中复现，不能保证永不掉线。** 旧版本未保存续期资料；现有凭据若已过期且没有有效网页会话，仍可能需要重新登录一次。部分官方登录不提供续期字段，平台撤销、风控、设备限制或刷新凭据本身失效仍需人工认证。
