# BuYu 2.0.11（2135）

## QQ 音乐登录

维护与新增功能：tiancaiProgramer。

- **后台自动续期**。BuYu 启动和回到前台时会检查 QQ 凭据，Android 后台任务也会在到期前尝试续期。成功后自动保存新凭据，网络暂时异常时会退避重试。
- **重新认证默认进入 QQ 扫码页**。凭据失效、需要补齐续期或手动选择「扫码认证」时，直接显示二维码。其他登录方式可在扫码页点击「官方网页登录」，取消后会回到扫码页。
- **小米／澎湃 OS 需要开启 BuYu 的「后台自启动」**。在系统设置中搜索「后台自启动」，为 BuYu 打开开关，允许应用进程退出后运行续期任务。[小米自启动权限说明](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1624)

## 安装与验证

- 提供原签名的 ARM64 和 ARM32 手机版，可在已有正式版上覆盖安装。下载后可使用 `SHA256SUMS` 核对文件。
- 427 项 Flutter 回归通过，5 项联网测试默认跳过。MIX Fold 3 已通过手动触发的真机验证，开启后台自启动后，BuYu 进程退出时，系统任务仍能换取新 QQ 凭据。真实续期时机由系统调度和 QQ 返回的有效期决定。
