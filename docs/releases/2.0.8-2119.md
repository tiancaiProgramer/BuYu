# BuYu 2.0.8（2119）本地正式包

日期：2026-10-29。维护与新增功能：**tiancaiProgramer**。暂不发布 GitHub。

## 每日发现

首页增加“网易云 / QQ音乐”切换，并记住最近选择。网易云保留原歌单与新歌推荐；QQ 使用官方推荐歌单列表，支持封面、歌曲数量、分页、刷新和失败重试。推荐列表无需登录也可浏览，播放使用 QQ 原曲目及当前账号权限。QQ 的推荐歌单与“每日 → QQ音乐”的每日推荐歌曲是不同入口。

推荐歌单详情可加入聚合收藏，并使用原有 QQ 播放、下载与评论功能；推荐歌单不显示编辑他人歌单的移除按钮。旧账号、原签名和包名保持兼容。

## 自动收藏同步

- 启动 App、完成登录、回到前台：读取两个已登录平台的 BuYu收藏，核对本地记录并上传待同步操作。
- 前台使用期间每五分钟核对一次，读取官方 App 或其他设备产生的收藏变更。
- 在 BuYu 收藏或取消收藏：先保存本地操作，再立即向歌曲所属平台上传；两平台各自保存，不做跨平台曲目匹配，不处理“我喜欢”或其他歌单。
- 已保存的操作在网络、服务或同步状态回写失败时保留待同步记录，前台按 10 秒、30 秒、1 分钟、2 分钟、5 分钟重试，此后最长每五分钟继续尝试。退出重开也能继续处理；未登录或属于其他账号的操作等待正确账号，不反复写入错误账号。初次本地保存失败则明确报错，不将尚未保存的操作显示为成功。
- 两个平台分别运行，同平台请求合并，单个平台连接慢不会阻塞另一平台的新收藏。
- 切到后台时尽力核对一次，随后停止轮询与重试定时器。系统强制结束、断电时无法保证最后一步执行，因此每次操作独立保存，不依赖退出同步。
- 本地尚未同步的增删优先；完整、成功读取当前账号歌单后，云端新增导入本地，云端删除从聚合收藏移除。读取失败、编号或分页不完整时保留本地数据。
- 整张 BuYu收藏 歌单不存在时，将本地已有的对应账号歌曲重新加入待同步并重建歌单，避免将歌单丢失误解为全部删除。
- 网易云使用完整歌曲编号核对成员关系，无法取得元数据的歌曲不会被误判成云端删除。写入成功后还需确认云端成员关系，才清除待同步状态。
- 本地文件夹分类独立保存，云端歌曲删除只更新聚合收藏；不修改本地分类目录。

手动读取和刷新按钮保留，作为立即核对或查看异常的入口，日常无需反复点击。没有常驻后台同步服务；重新联网后由下一次重试或回到前台触发。
