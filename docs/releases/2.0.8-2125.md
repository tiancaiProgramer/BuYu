# BuYu 2.0.8（2125）

维护与新增功能：**tiancaiProgramer**。

在 2124 的播放音质回退开关、严格档位下载基础上，补齐双源分类搜索、音乐缓存入口与可配置的聚合收藏连接。保留原作者 **2697a / sixbugs** 的版权声明及 MIT 许可；来源与第三方说明见 [CREDITS.md](../../CREDITS.md)。

## 本次更新

- **双源分类搜索**：歌单、专辑、歌手加入 QQ 音乐，与网易云结果组合显示，可按来源筛选、分页和重试，遵守“未登录隐藏”。QQ 结果按真实目录编号打开曲目，播放保持 QQ 来源；网易云结果保留原详情页。
- **音乐缓存**：本地音乐原入口调整为“音乐缓存”，保留网易云缓存读取，并增加 QQ 普通音频文件识别。按文件头检查，不改名或修改原文件。官方加密缓存不能只改名字播放，系统受保护目录可能无法读取；BuYu 在线播放不会自动保存完整音频，已下载歌曲仍在下载管理查看。
- **聚合收藏连接**：在聚合收藏右上角连接图标，或“设置 → 音乐账号与收藏 → 聚合收藏连接”，分别指定当前账号自己创建的普通歌单。未指定时继续使用/创建 BuYu收藏。
- 切换收藏歌单前可选择“合并并连接”“仅连接”或取消。合并会读取原连接歌单及当前同平台聚合收藏并添加到新歌单，不清空新旧歌单；读取失败保留原连接。仅连接保留本地已有收藏，后续新增收藏使用新连接。
- 连接按平台和账号保存。等待旧目标读写结束后再切换，阻止旧删除任务写入新歌单；目标失效时提示重新选择。

## 安装与验证

- ARM64 包约 **13.9 MB**，ARM32 包约 **13.7 MB**，最低 Android 5.0。
- 原包名 `com.sixbugs.bujuan`、原签名，可覆盖旧正式版保留数据。此次不提供共存版或 TV 下载。
- 完整自动回归 **377 项通过，5 项联网检查默认跳过**。独立匿名 QQ 联网检查验证了歌单、专辑、歌手搜索及对应真实曲目列表。
- MIX Fold 3 已从 2124 覆盖安装至 2125，启动后账号头像、两平台歌单和聚合收藏正常保留；实机确认四类搜索入口、双源单曲结果及收藏连接页默认状态正常。
- 收藏切换、合并和旧任务隔离经自动测试，未替用户确认真实云端歌单合并；QQ 缓存尚未验证实际设备文件播放。文件格式、系统权限和平台接口可用性可能影响结果。

安装包 SHA-256 见 `SHA256SUMS-2125.txt`。当前已安装 2125 正式包的测试手机无需重复安装。旧正式版可通过设置内的更新检查发现本版本。
