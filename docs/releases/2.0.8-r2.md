# BuYu 2.0.8-r2

维护与新增功能：**tiancaiProgramer**。

- 搜索分类固定显示“单曲、歌单、专辑、歌手”，去掉“双源”前缀。网易云/QQ音乐来源筛选和组合结果保留。
- 更新检查支持 -rN 修订版本，按数字比较修订号，同时兼容既有版本标签。
- 后续常规功能发布依次使用 2.0.9、2.0.10；文字、描述等小改使用当前版本的 -r2、-r3。Android 内部版本号持续递增，本次为2126。

25项相关自动检查通过，覆盖版本排序、旧版更新兼容、设置更新入口及横竖屏账号筛选。继承2125功能，完整功能和验证边界见 [2125说明](2.0.8-2125.md)。

安装包使用原包名和原签名，可覆盖旧正式版保留数据；提供 ARM64 / ARM32 手机包及 SHA256SUMS.txt，不发布TV包。
