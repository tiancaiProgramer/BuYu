# 播放降级开关与下载严格档位 / 2.0.8+2124

维护与新增功能：tiancaiProgramer。日期：2026-11-01。

按用户最新要求，播放与下载策略如下：

- 当前BuYu接入方式：QQ播放/下载最高保留无损，网易云最高保留Hi-Res；不将这个结论泛化为所有第三方客户端限制。QQ Hi-Res及重复“较高”选项继续移除。
- 设置新增“播放失败时自动降低音质”，默认开启。开启后，接口、地址、原生加载或开始播放后失败均可尝试同曲较低档位；网易云与QQ统一处理。
- 关闭后只请求所选档位，不接受服务端返回的低档替代资源；获取/加载失败不自动换到低档，原档重试仍失败后停止并提示。切换中关闭会取消旧请求链、按新策略重新处理；已正常播放的歌曲不因单纯切开关而重新加载。
- 下载固定按所选档位，不受播放开关影响。解析器与下载引擎均已移除自动降级入口，资源不可用、404、校验失败直接失败并提示；不会保存低档文件或重复发布半成品。
- 单曲下载菜单取平台支持档位、歌曲实际资源和账号下载上限的交集。网易云没有hr或hr大小为零时隐藏Hi-Res，QQ没有对应资源时同样隐藏；查询中不提前提供档位，失败可点击重试，全部不可用时显示说明。移除菜单中残留的自动回退文案。
- QQ旧Hi-Res偏好作为被移除档位，继续兼容读取为无损；这是旧设置迁移，不是当前下载在失败后降级。

网易云部分真实Hi-Res资源在URL接口中标为lossless。严格模式不会仅凭这个标签误拒绝：只有返回文件大小与官方该曲hr资源一致才接受；若只返回sq资源则拒绝。下载仍检查完整文件、MD5（官方提供时）、文件头；Hi-Res文件规格不足时不会保存。
