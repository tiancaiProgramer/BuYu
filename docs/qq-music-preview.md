## 使用方式

1. 设置 → 音乐账号与收藏，分别登录网易云与 QQ音乐。QQ 登录由应用内的官方 HTTPS 页面处理，密码、扫码和验证码留在官方页面。
2. 搜索中的“双源单曲”同时请求两个服务，可选全部 / 网易云 / QQ音乐。结果标明来源；同名的两个平台版本分别保留。歌单、专辑、歌手三个搜索标签目前仅查询网易云。
3. 当前播放队列可混合两种来源，切歌时请求对应服务的音频和歌词，使用各自账号的权限。音质按当前设置申请，不可用时向下回退；返回档位从音频链接类型识别，实际规格仍以文件头核验为准。
4. 歌曲三点菜单的“本地收藏”、播放页的心形按钮写入同一个本地收藏。没有登录也能保存歌曲资料；收藏不是音频下载，离线播放仍需要已下载文件。
5. “本地收藏”汇总两种来源。同步时，各平台的歌曲分别写入该平台账号下名为 **BuYu收藏** 的歌单，不做跨平台歌曲编号转换。网易云创建私密歌单；QQ歌单隐私遵循平台默认值。
6. 本地取消收藏会排队删除对应云端“BuYu收藏”中的歌曲。失败会保留待同步记录，右上角可重试。切换账号时旧账号绑定的待同步记录不会写入新账号，应切回原账号处理。

本地收藏不会自动导入或迁移旧的网易云“喜欢的音乐”，该列表仍保留。已经同步完成的记录不会在每次启动重新写入；若在官方客户端手动删除歌曲或整个同步歌单，本版没有自动对账恢复功能。服务端拒绝、登录失效、歌曲权限变化时可能无法播放或同步，界面保留重试提示。

## 会话与数据

QQ 请求使用独立客户端，只访问官方域名，不把 QQ Cookie 发送给网易云，也不使用共享账号或公共代理。会话仅在设备上保存：Android 6.0 及以上通过 Android Keystore 的设备密钥加密，文件放在不参与系统备份的目录；Android 5.x 只在进程内保留 QQ 会话，重启后需要重新登录。此设备加密密钥与 APK 发布签名不是同一用途，发布包继续使用原证书。

本地收藏数据库保存歌曲资料、来源、绑定账号和同步状态，不保存登录密码、QQ 会话或音频链接。原项目版权与 MIT 许可继续保留。

## 验证范围

2026-10-27 在连接的小米折叠手机、Android 16 上完成真实 QQ 官方登录、会员播放、歌词、横屏播放页、本地混合收藏持久化及指定云端歌单读写。测试使用本人登录的账号，未修改其他歌单。具体步骤与限制见 [真机验证记录](qq-music-device-verification.md)。上述音频规格属于测试曲目，不能推定所有歌曲或会员都能取得相同档位。

本轮修复了网页与客户端会话校验不一致、心形按钮状态不刷新、QQ 搜索类型与歌曲详情类型不同造成云端写入不可读，以及歌单编号字段差异的问题。现在收藏写入后必须再次读取云端歌曲确认结果；失败保留待同步状态，不把接口返回成功直接当作完成。

自动检查使用可控的网络响应和播放器，覆盖平台分流、来源筛选与横竖屏、登录失败保留原会话、云端业务失败、收藏持久化与快速反复操作、账号切换隔离和云端读回。最终完整回归 **154 项通过、3 项默认跳过**；真实搜索联网检查另行通过。静态检查无错误，仍有历史警告与样式提示。版本与签名核对结果随安装包记录。

只读联网检查：

```sh
flutter test --dart-define=BUYU_QQ_LIVE=true test/qq_music_live_test.dart
```

默认回归不会调用真实 QQ 账号，也不会联网创建或修改收藏歌单。接口研究来源见 [CREDITS.md](../CREDITS.md)。
