# BuYu 2.0.6（2066）网页登录认证

维护与新增功能：**tiancaiProgramer**。日期：2026-10-18。

## 当前入口

- **官方网页登录**：Android 应用内打开网易云 HTTPS 页面，默认显示官方手机号认证；手机号、验证码、密码及安全验证由网易云网页处理。完成认证后，应用独立校验会话、保存 Cookie 与账号资料，再返回。
- **二维码登录**：使用网易云音乐 App 扫码并确认，支持过期提示、刷新和关闭。

两个入口共用同一套实心按钮样式，背景、前景、圆角和高度一致。移除被平台风险限制的应用内密码、短信验证码直连表单；低层历史 API 保留兼容，不再作为 UI 登录方式。

个人信息页增加“切换账号”，无需先退出。横屏 / TV 登录弹窗也提供官方网页登录，进入网页时暂停二维码轮询。网页认证取消、会话无效或网络失败不会替换现有持久会话；验证成功后清理旧的同名会话 Cookie，避免新旧账号冲突。

## 手机号页面加载修正

2064、2065 设备迭代中，用户反馈从网页二维码切到手机号时仍持续转圈。当前入口采用官方 CtWebLogin 组件自身读取的顶层 `loginType=captchaLogin` 参数：

`https://music.163.com/?loginType=captchaLogin#/login`

该参数只选择官方页面初始展示方式；验证码发送、协议确认、风险验证与认证请求仍由原官方组件处理。没有代解验证码或跳过安全检查。

参考官方组件：[CtWebLogin 0.3.7](https://st.music.163.com/g/ct-web-login/ctWebLogin.main.0.3.7.1cebd5b7.js)。官方组件列出的 URS SDK 主地址和两个备用地址均为 HTTPS；应用对这份公共脚本的下载添加连接、读取超时和大小限制，并预加载资源。SDK 内容不存入源码，不携带 API 会话或用户输入去获取脚本。

网页底部播放器被隐藏，避免挡住登录方式按钮。原生 Activity 不导出，不添加账号 / 验证码 JavaScript 桥，拒绝无效 TLS 证书。应用只从固定网易云音乐主机取得会话，再向官方账号接口校验，不记录 Cookie 或凭据。临时本机诊断连接已移除，最终版关闭 WebView 调试。

## 二维码空框修正

项目深色主题将 `colorScheme.onSurface` 设为背景黑色，原先二维码入口的文字与图标因此不可见。两个登录按钮现在都使用 `primary/onPrimary` 的同一套实心样式；二维码弹层的刷新、关闭按背景明暗选择可读颜色。没有全局修改其他页面依赖的主题字段。
