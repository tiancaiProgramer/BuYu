# BuYu UI 一致性复核（2106，待用户选择）

维护与新增功能：**tiancaiProgramer**。

本轮只实施已经明确要求的两项功能：云盘登录提示、横屏登录三列布局。下表为对 2105 主题统一之后剩余差异的复核，**尚未据此改动样式**。依据是当前源码；没有将所有场景都标为真机复现。

| 编号 | 入口 / 位置 | 当前可核对的差异 | 建议与选择 |
| --- | --- | --- | --- |
| 1 | 登录页的“官方网页登录”“跳转主页”等主按钮 | 主按钮沿用灰色 ColorScheme.primary；来源选择标签、设置里的强调操作使用主题红色。新横屏布局也保留了该按钮配色 | 可以只把登录主按钮改为主题强调色，保留退出为次要描边按钮；不建议直接全局替换颜色，以免影响旧页面 |
| 2 | 云盘、旧设置页与账号 / 下载管理等新页面标题 | 云盘和部分设置标题保留“Here …～”、拼色大字；新增页面是普通 18 号粗体应用栏标题。字号、装饰和标题位置不同 | 选择保留原来的个性化大标题，或只把二级页面统一成紧凑标题。首页问候语可单独保留 |
| 3 | 歌曲三点菜单的“加入本地文件夹”“收藏到QQ歌单”；登录页操作图标 | 大部分入口使用 Tabler 轮廓图标，这些位置仍使用 Material 的文件夹、歌单、主页、网页、退出等图标，线条和视觉大小略有区别 | 可以统一为 Tabler 同类图标；不改变文字、入口顺序和功能 |
| 4 | 完整播放页的网易云评论与 QQ 评论 | 网易云是“热评榜 + 查看更多”及原评论排版；QQ 是“热评 / 最新”标签、分隔线、底部“加载更多”，头像、赞数位置和留白也不同。主题色已共用，但信息结构仍不同 | 可以统一头像大小、赞数位置、间距及排序标签的布局；平台支持的排序 / 分页能力仍各自保留，不能假定接口完全一致 |
| 5 | 原请求页面的加载 / 空白 / 网络错误，对比双源搜索、QQ 评论、下载管理 | 原页面使用大幅 Lottie 动画和笼统“网络错误”；新页面更多是文字、进度条或带“重试”的行内提示，插画尺寸、错误解释及恢复操作不同 | 建议统一成适合横竖屏的状态组件，明确区分未登录、网络失败、没有内容。本轮仅云盘的登录状态已处理，其他页面未改 |
| 6 | 搜索未输入时的热门搜索词，与搜索后的来源筛选标签 | 热搜词是旧实心圆角词块，来源筛选是带选中态的统一标签；留白、圆角和高度不同 | 两者分别是“立即搜索”与“筛选”，交互含义不同。可只统一尺寸 / 圆角，不建议把热搜词也做成可选中标签；也可以保留现状 |

## 已统一的部分

2105 已统一歌单 / 文件夹弹出菜单、新建改名删除对话框、来源筛选标签、下载音质选择、收藏目标选择、下载记录详情，以及新增账号 / 下载等页面的基础主题。不能把这些旧问题重复列为尚未修复。

本轮不重排主页、头像侧栏、播放页，不改用户已确认的卡片比例与间距。

## 本轮明确要求的修改

- 网易云云盘未登录：显示可点击的“请登录账号”，进入网易云登录页；QQ 单独登录不会被当成网易云云盘授权。
- 云盘接口返回 301 / 401：显示相同登录入口；真正的网络 / 服务错误仍保留错误状态。
- 横屏登录：左列平台切换，中列完整等大的二维码，右列扫码状态、提示和操作按钮，遵守安全区域。正常手机横屏不用整体下拉；极短窗口或放大字体时仅允许侧栏内容独立滚动，二维码保持完整可见。
- 账号、二维码授权与退出逻辑沿用现有流程，不清除真实登录状态。

## QQ 音乐云盘核对边界

当前 BuYu 云盘代码调用网易云 `/weapi/v1/cloud/get`，没有接入 QQ 云盘。已查阅腾讯微云的[官方帮助](https://www.weiyun.com/help.html)，可以确认微云本身有网盘上传、下载等功能；该资料不能证明最新版 QQ 音乐仍有可用的“微云音乐网盘”入口，也不能证明目前 QQ 音乐登录票据可直接读取微云。

公开旧教程提及 QQ 音乐的“微云音乐网盘”，但本轮没有用旧教程推断最新版仍然可用。连接手机未安装独立的 QQ 音乐官方客户端，暂时无法在官方客户端实测；因此当前状态记录为“最新版入口与可用接口未确认”，不标为“没有云盘”或“已经支持”。
