# QQ会话失效排查与恢复（2.0.9 / 2127）

维护与新增功能：tiancaiProgramer。保留原版权和MIT许可，随2.0.9正式手机包发布；不发布TV包。

用户反馈：QQ仍显示头像/已登录，但歌曲或歌单报错，重新登录才能恢复。此表现更接近服务端凭据失效或鉴权失败；尚未在本次实机中捕获自然过期错误，不将推断记为已复现。

## 已确认的代码问题

- 登录只保存音乐Cookie，QR授权返回的续期字段被丢弃；没有官方续期调用，loggedIn只判断字段是否存在，不代表凭据仍有效。
- Android读取加密会话时任何异常都删除文件；设备密钥暂时不可用也会造成不可逆丢失。
- Dart读取失败会记为已经恢复并清空会话，同一进程不再重试；公共头像缓存读取错误也可能影响会话。

## 修复

- 识别明确的1000/104400/104401鉴权错误，尝试当前账号官方Login续期；并发共用一次续期，失败限流，不因网络失败、普通接口业务失败、歌曲权限或空音源盲目续期。音源解析不再吞掉明确的鉴权失效提示。
- 保存QQ扫码返回的续期字段；网页登录中官方若提供同类字段，也分别保存。字段仅放原有设备绑定加密会话，不进入公共收藏库、普通请求Cookie或日志。恢复新凭据必须核对同一账号并验证官方资料，持久化成功后才替换旧凭据。
- 官方续期失败时可尝试同账号已有的更新后网页会话；不引入新账号、不自动弹网页登录，也不修改云端收藏。无法恢复时显示重新认证入口，保留旧记录。
- 读取异常不再删除文件、不为读取操作创建替代设备密钥；加密写入使用AtomicFile并串行，退出显式清除主文件和备份。临时读取失败保持可重试，回到前台再次尝试。旧格式兼容。
- 登录和退出使用修订号保护并串行持久化，迟到认证结果不能在退出后恢复旧登录。

## 验证与限制

完整回归383项通过，5项联网测试默认跳过；会话专项另核验前台重试等六种场景。静态检查无错误或警告。原有登录、头像、账号隔离测试通过。

旧版本未保存续期字段，若其凭据已过期且没有有效网页会话，仍可能需要重新登录一次以取得可保存的续期资料；部分官方网页登录不提供续期字段。账号风控、平台主动撤销、设备数限制及刷新凭证本身失效仍可能要求人工认证。未对真实用户账号模拟过期、修改加密文件或导出凭据；不能据模拟测试保证永不掉线。接口协议只参考既有QQMusicApi登录模块文档，未复制其实现。
