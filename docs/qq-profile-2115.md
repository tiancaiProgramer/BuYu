## 使用

仅 QQ 音乐登录时，各手机页面和侧栏使用 QQ 音乐官方头像、昵称。双账号登录后，在「设置 → 音乐账号与收藏 → 主页头像来源」选择网易云或 QQ 音乐；选择保存在本机，退出所选平台时自动使用另一个已登录账号。两个平台均退出时仍按原逻辑进入登录页。此选择只改变显示身份，不改变播放音源或账号登录。

QQ 公开头像资料按账号缓存，重启后刷新；退出会清理相应缓存，退出前发出的迟到请求不能恢复旧头像。QQ 头像的侧栏账号入口进入音乐账号管理。
