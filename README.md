# BuYu

**当前维护者：[tiancaiProgramer](https://github.com/tiancaiProgramer)**，负责本维护分支的后续开发、新增功能与问题修复。

这是 BuJuan 的社区维护版。原项目来源、原作者及第三方组件信息集中记录在文末“来源与致谢”和 [CREDITS.md](CREDITS.md)。

现已发布网易云 + QQ 音乐双音源版本：沿用现有界面，支持双源单曲搜索、混合播放、QQ 推荐歌单、聚合收藏自动核对与同步。当前更新和验证范围见 [2.0.8（2125）发布说明](docs/releases/2.0.8-2125.md)，推荐与同步规则见 [2120 说明](docs/releases/2.0.8-2120.md)，双音源完整功能与边界见 [基础功能说明](docs/releases/2.0.8-2116.md)。共存测试阶段记录见 [试用说明](docs/qq-music-coexist-preview.md)。

自 2026-10-18 起，应用对外名称改为 **BuYu**，后续新安装包统一使用 `BuYu` 前缀；以下已发布版本保留其原始名称和下载链接。

## 下载与安装

本次增加双源歌单、专辑和歌手搜索，统一音乐缓存入口，并支持按平台、账号指定聚合收藏连接歌单，切换时可确认是否合并。完整回归 377 项通过、5 项联网检查默认跳过，已在 MIX Fold 3 覆盖安装验证账号与歌单保留、搜索及连接页。详见 [2125 发布说明](docs/releases/2.0.8-2125.md)。

**2121 更新**修复每日、播客、每日发现，以及搜索和歌单管理未遵循“未登录隐藏”的遗漏；完整自动回归 309 项通过，MIX Fold 3 已分别验证两种单账号状态。旧正式版可通过“设置 → 检测更新”发现本次更新，详见 [2121 说明](docs/releases/2.0.8-2121.md)。

在原有横竖屏播放器内接入 QQ 音乐独立登录、双源单曲搜索、聚合收藏、每日/FM/播客、歌单管理和下载；优化账号退出、页面转场及播放栏布局。维护与新增功能：**tiancaiProgramer**。

## 2.0.6 更新

维护与新增功能：**tiancaiProgramer**。

- 完善手机横屏首页、头像侧栏、每日推荐、云盘、本地音乐、查看/管理及设置页；保留原版按钮和主题。
- 横屏播放页采用封面与播放控制、歌词、侧边功能分区，处理两侧摄像头安全区、状态栏对比度、封面与专辑渐变背景。
- 修复横屏首次进入每日推荐后无法返回、搜索转场残影，以及竖屏上一首和播放模式按钮无响应。
- 修复歌手页空白和头像加载，横屏显示两列歌手歌曲推荐，播放队列适配横屏。
- 自定义启动图、背景支持竖图自动适应横屏，也可分别设置横竖屏图片。
- 增加独立播放音质与下载音质选项，下载弹窗查询官方资源规格和账号下载权限。
- 歌曲三点菜单及播放页歌手入口均可下载，支持自选文件夹、进度和结果通知、失败重试及已下载歌曲离线播放。
- 修复默认选中“极高”时再次点击无法提交下载，以及部分主题下下载选项文字不可见。
- 继承 2.0.5 的播放稳定性、歌曲信息同步、系统媒体控制、本地曲库、二维码赞助移除和安装包精简修复。

以上为 2.0.6 的历史更新内容。当前 2124 的音源使用对应平台账号可获取的资源，不绕过账号权限；播放是否降级由设置开关控制，下载固定按所选档位，失败提示且不降级，完成后显示真实格式、采样率和位深。下载中断后可在下载管理重试，尚不保证应用被系统结束后持续下载或自动断点续传。

## 编译

验证环境：Flutter 3.24.5 / Dart 3.5.4、JDK 17、Android compileSdk / targetSdk 34。

```sh
flutter pub get
flutter test
# 手机，32 位与 64 位分包
flutter build apk --release --flavor mobile --split-per-abi --target-platform android-arm,android-arm64
# TV：必须同时指定 flavor 与 Dart define
flutter build apk --release --flavor tv --dart-define=BUJUAN_TV=true --split-per-abi --target-platform android-arm,android-arm64
```

本仓库保留其他平台源码，但本次交付与验证针对 Android。
